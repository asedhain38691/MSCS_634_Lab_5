# MSCS_634_Lab_5


This lab explored the application of two unsupervised learning methods—Hierarchical Clustering and DBSCAN—on the Wine dataset from scikit-learn. The purpose was to understand how different clustering techniques behave on a high-dimensional dataset, evaluate their performance, and interpret the resulting cluster structures using visualizations such as scatter plots and dendrograms. Throughout the lab, hierarchical clustering proved to be the more effective method, producing clean and meaningful clusters that closely aligned with the underlying wine classes, especially when using Ward linkage and selecting three clusters. In contrast, with DBSCAN, as initial eps values were too small, it resulted in all points being labeled as noise. This can be mitigated if we experiment with significantly larger eps values so that DBSCAN begins identifying cluster structure. However, it can remain sensitive to parameter changes and continued to classify several points as noise due to the dataset’s high dimensionality. A key challenge in this lab was determining appropriate DBSCAN parameters, which required analyzing a k-distance graph to identify a suitable eps range. Another decision involved selecting the number of clusters for hierarchical clustering, which was guided by interpreting the dendrogram and observing where natural separations occurred. Additionally, visualizing the clusters in two dimensions required reducing the complexity of the dataset, which may lose some information but still provided valuable insights. Overall, the lab provided a deeper understanding of clustering behavior, the importance of parameter tuning, and the strengths and limitations of each method when dealing with multidimensional data.
